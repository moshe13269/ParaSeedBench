# Released paper artifacts

These files are sufficient to verify the reported numerical claims without the
11,520 generated PNGs.

## `automatic_main/`

Original v0.2.4 outputs for the complete 96-scene automatic evaluator grid:

- `summary.csv`: category/all-scene estimates and bootstrap intervals;
- `case_metrics.csv`: one row per model–scene equivalent-wording grid;
- `paired_model_differences.csv`: paired scene differences;
- `counterfactual_controls.csv`: own-control and eligible discrimination results;
- `runtime.csv`: generation time, peak allocation, censor/black counts;
- `analysis_info.json`: split, grid size, bootstrap, and score hash;
- LaTeX fragments and category figure generated by the analysis.

The old `crossfit_worst_accuracy` field used the v0.2.4 even/odd split. It is
retained as historical output and is not a reported M96 result in the manuscript.

## `human_audit/`

- `human_a.csv`, `human_b.csv`: independent completed atomic states;
- `human_adjudicated.csv`: exactly the 144 disagreement IDs;
- `audit_key_after_unblinding.csv`: neutral-ID mapping and automatic states,
  released only after independent labeling and adjudication were complete;
- `selection.json`: the 16 prespecified selected scenes;
- `human_case_metrics.csv`: v0.3.0 metrics from resolved labels;
- `heldout_selected_worst_summary.csv`: all-35-split paper diagnostic and its
  metric-local 2,000-replicate intervals;
- agreement, evaluator-difference, and LaTeX outputs regenerated from raw labels.

`audit_info_reanalysis_v030.json` describes the release-side re-analysis. Its run
manifest hash refers to a temporary derivation wrapper, so use the immutable
`provenance/audit_info_original_v024.json` for the audit's link to the original
workstation run.

## `provenance/`

- original audit gate metadata supplied by the authors;
- the three v0.2.4 audit tables changed by the corrected held-out metric, retained
  under `original_v024_audit_outputs/` so the original audit hashes remain verifiable;
- immutable model/evaluator revision map;
- known workstation environment facts and the missing-manifest recovery step.

## Verification

`SHA256SUMS` covers every file below this directory except itself. Run:

```bash
python -m paraseedbench.verify_release
```

The command reconstructs the resolved human grid rather than trusting only the
derived tables.
